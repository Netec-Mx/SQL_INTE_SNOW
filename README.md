# SQL Intermediate con Snowflake

Este curso lleva las habilidades de SQL al siguiente nivel dentro del ecosistema Snowflake. El participante aprenderá a estructurar consultas complejas con CTEs y subconsultas, clasificar y transformar datos con lógica de negocio, identificar anomalías y duplicados, y aplicar window functions para análisis analítico avanzado. Además, desarrollará competencias en análisis temporal, auditoría de datos y optimización de queries para entornos de producción. Al finalizar, el participante podrá resolver problemas reales de calidad de datos, construir pipelines de análisis robustos y escribir SQL eficiente y mantenible a nivel profesional.
